# NC2024 NSCLC Methodology Audit (2026-04-25)

## Source

- **Paper**: Sanchez-Mejias et al., *Single-cell and spatial transcriptomics analysis of non-small cell lung cancer*, Nature Communications 15:4388 (2024).
- **DOI**: 10.1038/s41467-024-48700-8
- **PMC**: PMC11116453
- **Data**: ArrayExpress E-MTAB-13526
- **Cohort**: ~900k cells, 25 treatment-naive patients, NSCLC (adenocarcinoma + squamous-cell carcinoma) + adjacent non-involved tissue + healthy donors

## Method extracted from PMC11116453 (Methods section)

### Doublet detection
- **Tool**: Scrublet
- **Parameters**:
  - `expected_doublet_rate=0.06`
  - `min_counts=2`
  - `min_cells=3`
  - `min_gene_variability_pctl=85`
  - `n_prin_comps=30`
- **Scope**: Applied to merged cohort (tumor + background + healthy)
- **Notes**: Paper does not describe per-sample iteration. The cohort-level Scrublet at 900k cells implies either chunked execution or hardware capable of holding ~265 GB dense PCA. Our grouped path is biologically more conservative (intra-droplet doublet semantics) and memory-friendly — a defensible scientific improvement, not a downgrade.

### Batch correction / integration
- **Tool**: Harmony via `harmonypy` (Python)
- **Application**: applied separately to tumor and background/healthy datasets after PCA
- **Reason given**: "to account for additional technical variations arising between samples which are non-biological in origin"

### Clustering
- **Tool**: Leiden
- **Resolution**: 1.0
- **Embedding**: 15-dimensional harmonised PCA space
- **Visualization**: UMAP

### Differential expression
- **Marker genes**: Wilcoxon signed-rank test + Bonferroni correction. Filters: `min_logfc=0`, `min_pct=0.30` (gene expressed in ≥30% of cells)
- **DEA between conditions**: pseudobulk via `py_DESeq2`, including patient as covariate. Threshold: `median(padj) ≤ 0.05` and `|median(logFC)| ≥ 1`

### Cell type annotation
- Manual annotation based on marker gene expression and canonical genes, iteratively refined
- `scArches` label transfer used for consistency checking between tumor and B/H sub-datasets

### Software stack (confirmed)
- **Primary**: Scanpy (Python)
- **Mapping**: CellRanger v3.1.0
- **Other tools**: DropletUtils, Seurat, Pegasus, scVelo, clusterProfiler, CellPhoneDB, cell2location, CopyKAT v1.0.5

### Critical structural decision
The authors **split the cohort into two sub-datasets** before HVG selection / PCA / Harmony / clustering / annotation:
- **tumor sub-dataset**
- **background + healthy sub-dataset**

This is **NOT** a simple `--scale-mode` toggle — it is a separate analytical decision that affects which cells share an integration space.

## Implications for plan execution

1. **CSS is NOT the paper method.** It was a memory-driven approximation in our codebase. Replacing CSS with `sparse_exact` (TruncatedSVD + scanpy neighbors + Leiden) is a *complement* to the paper's design, not a deviation. **Plan Option A's sparse_exact upgrade = paper-faithful reproduction.**

2. **Doublet grouped is defensible.** Paper applies Scrublet to the merged cohort; we apply per-sample Scrublet with identical `n_pcs=30` and `doublet_rate=0.06`. The biological interpretation of doublet (intra-droplet co-encapsulation) is preserved by per-sample. Document this as a deliberate methodological refinement in the methodology audit ledger.

3. **Tumor/B+H split is a real gap.** Plan must ensure the integration step (Harmony) and downstream annotation can run on subsets. Either:
   - Add `--cohort-subset` flag to CLI (run pipeline on a subset of obs based on a column predicate), and chain two runs;
   - Or extend `paper_repro` to orchestrate the split internally.
   
   Decision: prefer the CLI flag approach — composable with existing checkpoint/resume.

4. **Parameter alignment must be enforced.** Current launcher does not pin `n_pcs=15` or `leiden_resolution=1.0` to paper values. The new launcher must set these explicitly via CLI args or config defaults to ensure reproduction.

5. **No dual-path needed.** Plan originally had `--repro-mode strict` vs `improved`. Drop this. Single path = paper-faithful Scanpy/Harmony/Leiden, with `sparse_exact` as the always-on PCA implementation. Document as: "We reproduce the paper's method using sparse-aware PCA (no information lost) and per-sample Scrublet (biologically conservative). All other parameters match the paper exactly."

## Outstanding methodology questions

- Paper does not specify HVG `n_top_genes` count. Standard Scanpy default is 2000-3000; verify by re-reading paper supplementary methods if it specifies.
- Paper uses `n_prin_comps=30` for Scrublet but `15 PCs` for downstream clustering. We should keep this asymmetry — Scrublet runs on its own PCA internally.
- `min_pct=0.30` for marker is high; common Scanpy default is 0.10. Confirm via supplementary if available.

## Audit verdict

**Plan Option A path is paper-faithful.** Proceed with the 8-phase refactor (`scale_mode` decomposition / densify policy / memory enforcer / staircase / R contract / module audit / 884k staircase / Mac round-trip), enforcing paper parameters as the canonical defaults.
